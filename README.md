# 🍪 Кликер-бот для Cookie Clicker (YOLOv8)

Автоматический кликер для Cookie Clicker: YOLOv8 находит печеньку и самостоятельно наводит на неё курсор, кликает нативными WinAPI-вызовами, а каждые 7 секунд прокликивает апгрейды в правой колонке снизу вверх.

## Возможности

- 🎯 **Автонаведение на печеньку** — YOLO ищет печеньку (класс `game`) каждые ~1.5 сек и двигает курсор к ней; вручную наводиться не нужно
- 🖱️ **WinAPI-клики** — клики через `mouse_event`, курсор не дёргается, нет задержек pyautogui
- ⬆️ **Апгрейды по прямоугольнику** — YOLO находит прямоугольник апгрейдов (правая колонка) и кликает по нему снизу вверх по одному разу на позицию, каждые 7 секунд
- ⏸️ **Пауза по пробелу** — жмите **Пробел** в любой момент: бот ставится на паузу, ещё раз — продолжает
- 🛑 **Аварийная остановка** — Ctrl+C или мышь в угол экрана (`pyautogui.FAILSAFE`)

## Классы объектов

| Класс | ID | Описание |
|-------|----|----------|
| `game` | 0 | Печенька (игровое поле) |
| `ad_close` | 1 | Кнопка закрытия рекламы — есть в модели, но логика закрытия рекламы в боте отключена |
| `upgrade` | 2 | Прямоугольник апгрейдов (правая колонка) |

> Апгрейды детектятся как **один большой прямоугольник** (вся правая колонка), а не каждый апгрейд по отдельности. Бот кликает внутри него по сетке снизу вверх.

## Быстрый старт

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Сбор данных (скриншоты -> screenshorts/)
python screener.py

# 3. Создание эталонов для авторазметки
python crop_template.py screenshorts/<файл>.png game
python crop_template.py screenshorts/<файл>.png upgrade

# 4. Авторазметка
python autolabel.py --preview preview

# 5. Разбивка датасета и обучение
python split_dataset.py --clean
python train.py

# 6. Запуск бота
python app.py
```

Если обученная модель уже есть — бот найдёт её автоматически в `runs/detect/*/weights/best.pt`, либо укажите путь явно:

```bash
python app.py --model путь/к/best.pt --conf 0.2
```

## Правила разметки

- **game** — рамка вокруг печеньки
- **upgrade** — прямоугольник на всю правую колонку с апгрейдами (не отдельные кнопки). Чем точнее рамка, тем точнее бот попадает по кнопкам
- Минимум **30–50 примеров** на класс
- Если мелкие объекты плохо детектятся — увеличьте `imgsz` в `train.py` (до 960)

## Как работает бот (`app.py`)

```python
python app.py
```

1. **Старт** — YOLO ищет печеньку (до 10 попыток), наводит курсор
2. **Основной цикл**:
   - каждые ~1.5 сек — переприцел на печеньку (YOLO)
   - каждые **7 сек** — проход по апгрейдам: свежая детекция прямоугольника, клики снизу вверх (шаг 35px), возврат на печеньку
   - между этим — быстрые клики по печеньке (20/сек)
3. **Пробел** — пауза/продолжение (срабатывает по нажатию)
4. **Ctrl+C / мышь в угол** — остановка

### Настройки (в начале `app.py`)

| Константа | Значение | Назначение |
|-----------|----------|------------|
| `UPGRADE_INTERVAL` | `7.0` | Периодичность прохода по апгрейдам (сек) |
| `UPGRADE_STEP` | `35` | Шаг сетки кликов по вертикали (px) |
| `UPGRADE_Y_START` | `400` | Верхняя граница зоны прокликивания |
| `UPGRADE_Y_END` | `1045` | Нижняя граница зоны прокликивания |
| `COOKIE_CHECK_INTERVAL` | `1.5` | Переприцел на печеньку (сек) |
| `CLICK_INTERVAL` | `0.05` | Пауза между кликами печеньки (сек) |


## Требования

- Python 3.8+
- Windows (клики через WinAPI `ctypes`; на macOS/Linux клики работать не будут)
- Зависимости: `ultralytics`, `pyautogui`, `opencv-python`, `numpy`
